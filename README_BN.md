# বাংলাবিদ — ধাপে ধাপে চালু করার গাইড (ক্লিক বাই ক্লিক, কোনো কোডিং লাগবে না)

টার্মিনাল বা গিট কমান্ড কিছুই লাগবে না — শুধু ব্রাউজারে মাউস দিয়ে ক্লিক করেই পুরো
ওয়েবসাইট লাইভ করা যাবে। ধাপগুলো ক্রমানুসারে করুন।

আজ এই গাইড **রেজিস্ট্রেশন সিস্টেম** লাইভ করা পর্যন্ত নিয়ে যায়। এক্সাম সেন্টার ও
স্টুডেন্ট লগইন পরের ধাপে যোগ হবে।

---

## ধাপ ১ — Google Sheet তৈরি করুন (ডেটাবেস)

1. [sheets.google.com](https://sheets.google.com) এ যান, **Blank** ক্লিক করুন।
2. উপরে বাম দিকে নাম দিন: `Banglabid Database`।
3. ব্যস, এটুকুই — কোনো ট্যাব বা হেডার নিজে লিখতে হবে না, পরের ধাপে সব অটোমেটিক হয়ে যাবে।

---

## ধাপ ২ — Google Apps Script (API সার্ভার) — একবারে সব অটো-সেটআপ

1. শিটের উপরের মেনু থেকে **Extensions → Apps Script** ক্লিক করুন। নতুন ট্যাব খুলবে।
2. এখানে যা লেখা আছে (`function myFunction() {}`) সব সিলেক্ট করে (`Ctrl+A`) মুছে ফেলুন।
3. এই প্রজেক্টের `apps-script/Code.gs` ফাইলের **সম্পূর্ণ কোড কপি করে** এখানে পেস্ট করুন।
   (এখানে **কোনো Sheet ID বসাতে হবে না** — কোডটা নিজেই বুঝে নেবে এটা কোন শিটের সাথে যুক্ত।)
4. উপরে ফ্লপি-ডিস্ক আইকনে ক্লিক করে **Save** করুন, প্রজেক্টের নাম দিন `Banglabid API`।
5. এখন উপরের দিকে একটা ড্রপডাউন মেনু দেখবেন যেখানে ফাংশনের নাম দেখায় (হয়তো `doGet` লেখা
   আছে)। সেই ড্রপডাউনে ক্লিক করে **setup** সিলেক্ট করুন।
6. ড্রপডাউনের পাশে **▶ Run** বাটনে ক্লিক করুন।
7. প্রথমবার একটা পপআপ আসবে অনুমতি চেয়ে (**Authorization required**) — **Review permissions**
   ক্লিক করুন → আপনার Google অ্যাকাউন্ট সিলেক্ট করুন → "Advanced" লেখায় ক্লিক করুন →
   "Go to Banglabid API (unsafe)" ক্লিক করুন → **Allow** ক্লিক করুন।
8. আবার **▶ Run** বাটনে ক্লিক করুন (এবার আর পপআপ আসবে না)। নিচে **Execution log**-এ
   "সেটআপ সম্পন্ন!" লেখা দেখবেন।
9. আপনার Google Sheet-এ ফিরে যান (আগের ট্যাবে) — দেখবেন **Registrations**, **Settings**,
   **Admins** নামে তিনটা ট্যাব, হেডারসহ, নিজে থেকেই তৈরি হয়ে গেছে। **Admins** ট্যাবে একটা
   ডিফল্ট লগইনও বসানো আছে:
   - Username: `admin`
   - Password: `banglabid2026`
   (সাইট লাইভ করার পর এই পাসওয়ার্ড বদলে ফেলবেন — শুধু Admins শিটের ওই ঘরে গিয়ে নতুন
   পাসওয়ার্ড টাইপ করে দিলেই হবে।)

### এখন ওয়েব API হিসেবে পাবলিশ করুন

10. Apps Script ট্যাবে ফিরে যান। উপরে ডান দিকে নীল **Deploy** বাটনে ক্লিক করুন →
    **New deployment**।
11. Deployment type-এর পাশে গিয়ার (⚙️) আইকনে ক্লিক করে **Web app** সিলেক্ট করুন।
12. সেট করুন:
    - **Execute as:** Me
    - **Who has access:** Anyone
13. **Deploy** ক্লিক করুন। আবার অনুমতি চাইলে ধাপ ৭-এর মতো Allow করুন।
14. একটা **Web app URL** দেখাবে, এরকমঃ `https://script.google.com/macros/s/xxxxxxxxxxxx/exec`
    — এই পুরো লিংকটা কপি করে কোথাও নোট করে রাখুন। এটাই আমাদের API URL।

> ⚠️ পরে `Code.gs`-এ কোনো পরিবর্তন করলে **Deploy → Manage deployments → পেন্সিল আইকন →
> Version: New version → Deploy** করতে হবে, নাহলে পরিবর্তন লাইভ সাইটে আসবে না।

## ধাপ ৩ — API URL ফ্রন্টএন্ড ফাইলে বসান

1. আপনার কম্পিউটারে extract করা `banglabid-website` ফোল্ডারে যান।
2. `.env.example` নামের ফাইলটা খুঁজুন। এর উপর রাইট-ক্লিক করে **Rename** করুন, নাম দিন `.env`
   (শুরুতে ডট সহ, `.example` অংশটা বাদ দিয়ে)।
3. ফাইলটা যেকোনো টেক্সট এডিটর (Notepad/TextEdit) দিয়ে খুলুন। এতে লিখুন:
   ```
   VITE_API_URL=https://script.google.com/macros/s/xxxxxxxxxxxx/exec
   ```
   (ধাপ ২.১৪-এর URL বসান, সেভ করুন।)

## ধাপ ৪ — GitHub অ্যাকাউন্ট তৈরি করুন

1. ব্রাউজারে যান **github.com** → উপরে ডান দিকে **Sign up**।
2. ইমেইল দিন → **Continue** → পাসওয়ার্ড দিন → **Continue** → ইউজারনেম দিন → **Continue**।
3. ভেরিফিকেশন পাজল সমাধান করুন।
4. ইমেইলে আসা কোড বসিয়ে **Verify**।
5. এরপরের প্রশ্নগুলোতে নিচে **Skip personalization** থাকলে সেটায় ক্লিক করতে পারেন।

## ধাপ ৫ — নতুন Repository তৈরি করুন

1. লগইন করা অবস্থায় উপরে ডান দিকে **+** → **New repository**।
2. **Repository name:** `banglabid`
3. **Public** সিলেক্ট করা আছে কিনা দেখে নিন (ডিফল্ট এটাই)।
4. **Add a README file** বক্সে ✅ **দেবেন না**।
5. সবুজ **Create repository** ক্লিক করুন।

---

## ধাপ ৬ — ফাইল আপলোড করুন (Push, ব্রাউজার দিয়ে)

1. রিপোজিটরির পেজে **uploading an existing file** নীল লিংকে ক্লিক করুন
   (না পেলে: **Add file** বাটন → **Upload files**)।
2. আপনার কম্পিউটারে `banglabid-website` ফোল্ডারটা **খুলুন** (ভিতরে ঢুকুন)।
3. ভিতরের সব ফাইল/ফোল্ডার সিলেক্ট করুন (`Ctrl+A` / Mac এ `Cmd+A`)। মনে রাখবেন —
   `.env` ফাইলটাও এই সিলেকশনে থাকবে, সমস্যা নেই।
4. সিলেক্ট করা সব ফাইল **ড্র্যাগ করে** GitHub-এর আপলোড বক্সে **ছেড়ে দিন**।
5. আপলোড শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
6. নিচে স্ক্রল করে সবুজ **Commit changes** বাটনে ক্লিক করুন।

আপনার কোড এখন GitHub-এ — এটাই "push" করা।

## ধাপ ৭ — Netlify-তে হোস্ট করুন

1. নতুন ট্যাবে **netlify.com** → **Sign up** → **Sign up with GitHub**।
2. GitHub পপআপে **Authorize netlify** ক্লিক করুন।
3. Netlify ড্যাশবোর্ডে **Add new site → Import an existing project**।
4. **Deploy with GitHub** ক্লিক করুন, তালিকা থেকে **banglabid** বেছে নিন।
   (না দেখালে **Configure Netlify on GitHub** ক্লিক করে GitHub-এ গিয়ে অ্যাক্সেস দিন।)
5. Build settings ঠিক আছে কিনা দেখুন:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
6. **Show advanced** ক্লিক করুন → **New variable**:
   - Key: `VITE_API_URL`
   - Value: (ধাপ ২.১৪-এর Apps Script URL — আবার বসান, .env ফাইলটা এখানে কাজ করে না,
     Netlify-কে আলাদাভাবে বলে দিতে হয়)
7. সবুজ **Deploy banglabid** ক্লিক করুন। ২-৪ মিনিট অপেক্ষা করুন।
8. উপরে **"Published"** দেখলে সাইট লাইভ। একটা লিংক দেখবেন যেমন
   `random-name-12345.netlify.app` — ক্লিক করে দেখে নিন।

### সাইটের নাম সুন্দর করা (ঐচ্ছিক)
**Site configuration → Change site name** → নতুন নাম দিন (যেমন `banglabid`) → **Save**।
এখন লিংক হবে `banglabid.netlify.app`।
